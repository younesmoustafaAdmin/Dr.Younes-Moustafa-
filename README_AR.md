# مشروع تطبيق عيادة د. يونس — نسخة تجريبية

هذا المشروع يغلّف ملف HTML المرفق داخل تطبيق Android باستخدام WebView، ويمكن بناء APK من GitHub Actions دون كمبيوتر محلي.

## تنبيهات مهمة قبل استخدامه ببيانات حقيقية
- بيانات المرضى تُحفظ محلياً داخل بيانات التطبيق على الجهاز. حذف التطبيق أو مسح بياناته قد يؤدي إلى فقدان البيانات؛ استخدم النسخ الاحتياطي داخل التطبيق بانتظام.
- الملف الأصلي يحتوي على محاولة مزامنة تعتمد على بيئة `window.claude`، وهي غير متوفرة عادةً في تطبيق Android مستقل؛ لذلك لا تعتمد على المزامنة السحابية في هذه النسخة.
- خطوط Google وبعض الوظائف الخارجية تحتاج إلى إنترنت. واجهة التطبيق والملف الأساسي موجودان داخل التطبيق.
- هذا مشروع أولي؛ اختبر إضافة المرضى والمواعيد والصور والنسخ الاحتياطي والطباعة قبل استخدامه سريرياً. لا تضع بيانات مرضى حقيقية قبل التأكد من الأمان والخصوصية والنسخ الاحتياطي.

## بناء APK من الهاتف عبر GitHub
1. أنشئ مستودعاً جديداً على GitHub وارفع **محتويات** هذا المجلد إليه (ليس ملف ZIP نفسه).
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Android APK** ثم **Run workflow**.
4. انتظر انتهاء البناء بنجاح.
5. افتح نتيجة التشغيل، ثم قسم **Artifacts** ونزّل `younes-clinic-apk`.
6. فك ضغط الملف المنزّل، ثم افتح `app-debug.apk` على هاتفك وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

إذا ظهر خيار Actions معطلاً، افتح تبويب Actions وفعّله للمستودع. لا ترفع بيانات مرضى أو نسخاً احتياطية إلى GitHub.
